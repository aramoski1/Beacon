## 1. Owner and tenant books

**Why:** Stop living in Excel Owners/Tenants sheets. Work the book in Workspace, then generate a weekly merge.

### How to use

**Contacts book**

- Workspace → **Contacts**
- Toggle **All / Owners / Tenants**
- Tenant rows show occupancy: property, leased SF, expiry, landlord
- Create/import a contact: **Book** (owner / tenant / other) is required

**This week**

- Main nav → **This week**
- Pin a Contacts smart list (or it falls back to cadence-due in the next 7 days)
- Log call outcomes, email, or **Generate drafts** for the whole list → Outreach

**Merge tokens** (campaign settings, or **Merge only — skip AI**):
`{first_name}` `{name}` `{address}` `{sf}` `{landlord}` `{expiry}`

**Lease abstracts**

- Abstract a lease; if it states tenant name, Beacon can create/link a tenant contact
- Fields: leased SF, landlord name
- Option-notice and 1031 dates show on the Today desk

**Promote owner**

- Property page → promote the county/Sunbiz owner into the CRM as an owner contact

### Honest limit

Beacon still does **not** send mail. Flow is: draft → open in Gmail/Outlook → **Mark as sent**. Connections OAuth is still a stub.

## 2. Find listing specs (do not clobber county data)

**Why:** Tax roll has owner, SF, and sales. It does **not** have docks, clear height, power, or asking rent. Those live on listing flyers. Most book rows never had a pasted URL.

Beacon can now **search for a public listing**, extract only what is stated, and write **empty unlocked fields only**.

### Lock rules (always on)

Never overwritten by search, scrape, document enhance, or county re-run:

- Fields tagged `county`, `manual`, or `sunbiz`
- Owner name, building SF, land SF, last sale date/price if they already have a value
- Anything you type on **Industrial / flex specs** (tagged `manual`)

Fill-only: industrial specs and other `extract` custom fields, and only if empty.

### How to use — one property

1. Open a property with an address (example that worked: **3880 W 104th St**).
2. Either:
   - Industrial card → **Find listing specs** (shows when the card is mostly empty), or
   - Data sources → **Listing specs**, or
   - **Enrich → Find listing specs**
3. Wait for search. Preview shows only empty fields with a **citation** (URL + excerpt).
4. **Nothing is saved yet.** Check the ones you want → click **Fill N empty fields**.
5. Source tag on those fields: **Listing** (`web`).

Search alone does not write the industrial card. If you only clicked Find listing specs and left the page, the specs stay empty.

If nothing is stated on a cited, address-matched page (or snippet), the card stays empty. That is correct.

**Still works as before:** Enrich → **Document or URL** — paste a flyer, OM, or listing URL yourself.

### How to use — many properties

1. Workspace → **Properties**
2. Select rows → **Enrich selected**
3. Choose **Listing specs** (not County + Sunbiz)
4. **Queue listing search**
5. Jobs store a preview. **Nothing is auto-applied.** Open each property to accept.

Cap: 25 properties per queue.

### Keys (`.env.local` and Vercel)

You only need **Brave** for search. Jina is used for pages that allow a fetch.

| Key | Role |
|---|---|
| `BRAVE_SEARCH_API_KEY` | Search (preferred) |
| `JINA_API_KEY` | Fetch public pages when they are not blocked |
| `SERPER_API_KEY` | Optional; unused if Brave is set |

Restart `npm run dev` after changing keys.

**Live site:** `.env.local` is not used on Vercel. Add `BRAVE_SEARCH_API_KEY` (and `JINA_API_KEY`) in Vercel → Project → Settings → Environment Variables → **Production**, then **Redeploy**. Without that, Find listing specs on the live site will say search is not configured.

### What happens under the hood

1. Search: `"address" "city" (industrial OR warehouse OR clear height OR docks OR Crexi OR LoopNet)`
2. Try Jina on the listing URL
3. **If LoopNet/Crexi block Jina** (they usually do): use Brave’s public snippets, only if they match the street number + street name
4. Claude extracts **only stated** specs
5. You accept → write empty unlocked fields

Snippets are why 3880 W 104th filled (32' clear, 2 docks, 250A, ESFR). Treat them as **quoted search text**, not a live flyer download.

### Honest limits

- Will **not** invent a full industrial card for every tax-roll folio
- Will **not** log into LoopNet, Crexi, or CoStar
- Snippets can be incomplete or mix a park vs a suite — **read the excerpt before you apply**
- Apollo / people-find is **not** built (that was v1.5, people only, not specs)
